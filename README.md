# Terraform Labs ☁️

This repository contains my hands-on work with Terraform for Infrastructure as Code (IaC), focused on understanding cloud infrastructure provisioning and configuration management.

## 🚀 Purpose
Develop practical skills with Terraform to build, structure, and manage infrastructure as code, with attention to security best practices and operational awareness.

## 🧠 Scope

This repository includes:

- Terraform project initialization and structure
- Infrastructure as Code configuration patterns
- State file management concepts
- Resource definition and dependency handling
- Secure handling of local and sensitive files

## 🔐 Security Awareness

Basic security practices are applied during development, including:

- Exclusion of sensitive files such as `.pem`, `terraform.tfstate`, and `.terraform/`
- Awareness of secret exposure risks in infrastructure code
- Separation of local environment artifacts from version control

## 🛠️ Technologies
- Terraform
- Git
- GitHub

## 🎯 Focus
This repository reflects my learning and practical exploration of Infrastructure as Code concepts applied to cloud environments.
